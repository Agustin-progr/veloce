# VELOCE | Catálogo Premium de Automóviles

**VELOCE** es un proyecto de desarrollo frontend que combina diseño moderno, elegancia y funcionalidad para crear una experiencia digital de exploración de vehículos premium.

El objetivo es ofrecer un catálogo automotriz con una interfaz intuitiva, una estética sofisticada y herramientas interactivas que permitan descubrir y comparar vehículos de manera sencilla.

## Características principales

- **Diseño premium:** interfaz moderna, tipografía cuidada y una identidad visual elegante.
- **Catálogo dinámico:** visualización de vehículos mediante tarjetas interactivas.
- **Filtros por categoría:** exploración de vehículos según su tipo.
- **Búsqueda:** localización de vehículos por nombre.
- **Ordenamiento:** organización de los resultados según las opciones disponibles.
- **Favoritos:** guardado de vehículos favoritos mediante el almacenamiento local del navegador.
- **Información detallada:** ventana con información específica de cada vehículo.
- **Diseño adaptable:** experiencia optimizada para computadoras, tablets y celulares.
- **Menú adaptable:** navegación diseñada para diferentes tamaños de pantalla.
- **Formulario de contacto:** preparación de un correo electrónico mediante la aplicación de correo predeterminada del visitante.

## Tecnologías utilizadas

## Instalación y ejecución

1. Descargá o cloná el repositorio.
2. Abrí la carpeta del proyecto en Visual Studio Code.
3. Instalá la extensión **Live Server**, si todavía no la tenés.
4. Hacé clic derecho sobre `index.html` y seleccioná **Open with Live Server**.
5. Explorá el catálogo y probá sus funcionalidades.

También podés abrir `index.html` directamente en un navegador, aunque utilizar un servidor local es recomendable durante el desarrollo.

## Personalización

El proyecto puede adaptarse a las necesidades de una concesionaria o marca automotriz mediante la modificación de los vehículos, las imágenes, las especificaciones y los datos de contacto.

Antes de utilizarlo comercialmente, se deben verificar los datos publicados, configurar el contacto y comprobar los permisos de uso de las imágenes.
